# Assignment 03: Conditional Statements and Loops

## Aim
To learn decision-making statements and loops in JavaScript.

## Theory

### 1. Conditional Statements
Conditional statements execute different blocks of code depending on a condition. The `if`, `else if`, and `else` statements are used for decision-making.

For example, a student's marks can be checked to determine a grade.

### 2. For Loop
A `for` loop repeats a block of code for a specified number of iterations. It usually contains initialization, a condition, and an update expression.

### 3. While Loop
A `while` loop repeatedly executes a block while its condition remains true. The condition should eventually become false to prevent an infinite loop.

### 4. Accumulation
A variable can store a running total by adding values during each iteration.

## Tasks
1. Determine grades using conditional statements.
2. Print values using a `for` loop.
3. Calculate a total using a `while` loop.

## Conclusion
This assignment develops logical thinking through conditional execution, repetition, and accumulation.
