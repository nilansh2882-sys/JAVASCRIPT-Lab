# Assignment 01: Introduction to JavaScript

## Aim
To understand the basics of JavaScript, including displaying output, declaring variables, and identifying data types.

## Theory

### 1. Introduction to JavaScript
JavaScript is a programming language used to make web pages interactive and dynamic. It can run in web browsers and outside browsers using environments such as Node.js.

### 2. Displaying Output
JavaScript provides `console.log()` to display information in the browser console. The `document.write()` method can also write content directly into an HTML document.

### 3. Variables
Variables store data that can be used and modified during program execution.
- `var`: Function-scoped or globally scoped variable.
- `let`: Block-scoped variable that can be reassigned.
- `const`: Block-scoped variable that cannot be reassigned.

### 4. Data Types
JavaScript supports data types such as String, Number, Boolean, Undefined, Null, BigInt, Symbol, and Object.

The `typeof` operator identifies the type of a value.

## Tasks
1. Display a message using JavaScript inside an HTML file.
2. Declare and display variables using JavaScript.
3. Identify data types using the `typeof` operator.

## Conclusion
This assignment introduces JavaScript syntax, variables, output methods, and data types, which form the foundation for further programming.
