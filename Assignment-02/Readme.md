# Assignment 02: Operators and Type Conversion

## Aim
To understand arithmetic operators, type conversion, and operator-based calculations in JavaScript.

## Theory

### 1. Arithmetic Operators
Arithmetic operators perform mathematical calculations.
- `+`: Addition
- `-`: Subtraction
- `*`: Multiplication
- `/`: Division
- `%`: Remainder
- `**`: Exponentiation

### 2. Type Conversion
Type conversion changes a value from one data type to another. JavaScript supports explicit conversion using functions such as `Number()`, `String()`, and `Boolean()`.

For example, `Number("25")` converts the string `"25"` into the number `25`.

JavaScript may also perform implicit type conversion during operations.

### 3. Operators and Calculations
Operators can be combined with variables and conditional statements to create simple calculators. The result depends on the operator, operand types, and operator precedence.

## Tasks
1. Perform arithmetic operations.
2. Demonstrate type conversion.
3. Create a calculator using operators.

## Conclusion
This assignment demonstrates how JavaScript performs mathematical operations and converts values between data types.
