# Assignment 09: DOM and Browser Interaction

## Aim
To understand how JavaScript interacts with HTML elements and responds to user actions.

## Theory

### 1. Document Object Model (DOM)
The DOM represents an HTML document as a tree of objects. JavaScript can access and modify these objects to update a web page dynamically.

### 2. Event Handling
Events represent actions such as clicks, input changes, and form submissions. JavaScript can register event listeners using `addEventListener()`.

### 3. Form Validation
Form validation checks whether user input meets required conditions before processing it. Examples include checking whether a field is empty or whether an input has the correct format.

### 4. Local Storage
The Web Storage API provides `localStorage` for saving key-value data in a browser across page reloads. Values are stored as strings, so objects generally require JSON serialization and parsing.

### 5. Interactive Applications
A quiz application can combine HTML elements, event listeners, conditions, and score calculations to provide interactive behavior.

## Tasks
1. Respond to a DOM button click.
2. Validate form input.
3. Store or retrieve data using local storage and implement quiz behavior as specified.

## Conclusion
This assignment demonstrates how JavaScript connects web-page structure, user interaction, validation, and browser storage.
