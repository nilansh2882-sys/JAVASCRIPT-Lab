# Assignment 05: Arrays and Array Methods

## Aim
To understand arrays and use common array methods to process data.

## Theory

### 1. Arrays
An array stores multiple values in a single variable. Array elements are accessed using zero-based indexes.

Example:

```javascript
const marks = [75, 82, 90];
```

### 2. forEach()
The `forEach()` method executes a callback function for each array element. It is commonly used to perform an action on every item.

### 3. filter()
The `filter()` method creates a new array containing elements that satisfy a specified condition.

### 4. Nested Arrays
A nested array is an array that contains other arrays. It can represent tabular or grouped data.

## Tasks
1. Create and display an array of marks.
2. Use `forEach()` and `filter()` to process array elements.
3. Work with nested arrays.

## Conclusion
This assignment introduces arrays and methods for iterating over, selecting, and organizing data.
