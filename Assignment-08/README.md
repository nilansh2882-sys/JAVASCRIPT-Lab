# Assignment 08: Inheritance and Object Composition

## Aim
To understand inheritance and composition as techniques for organizing and reusing JavaScript code.

## Theory

### 1. Inheritance
Inheritance allows one class or object to reuse properties and methods from another. In JavaScript, classes can use the `extends` keyword to inherit from another class.

The `super` keyword is used to call a parent class constructor or method.

### 2. Encapsulation
Encapsulation groups related data and behavior together and controls how an object's internal state is accessed or modified.

### 3. Object Composition
Composition builds complex behavior by combining smaller objects or components instead of relying entirely on inheritance.

### 4. Reusability
Both inheritance and composition help reduce duplicated code. Inheritance models an "is-a" relationship, while composition often models a "has-a" relationship or combines capabilities.

## Tasks
1. Demonstrate inheritance.
2. Implement an object or class representing a locker.
3. Demonstrate object composition.

## Conclusion
This assignment explains different ways to structure reusable code and model relationships between objects.
