# Assignment 07: Objects and Prototypes

## Aim
To understand JavaScript objects, constructors, and prototypes.

## Theory

### 1. Objects
Objects store related information as key-value pairs called properties. They can also contain methods, which are functions associated with an object.

### 2. Constructor Functions
A constructor function can initialize properties for multiple objects. The `new` keyword creates an instance from a constructor function.

### 3. The `this` Keyword
The value of `this` depends on how a function is called. In a constructor invoked with `new`, `this` refers to the newly created object.

### 4. Prototypes
Every ordinary JavaScript object has an internal prototype link. Objects can inherit properties and methods through the prototype chain.

Methods placed on a constructor's prototype can be shared by its instances.

## Tasks
1. Access and examine object properties.
2. Create objects using a constructor function, such as a book constructor.
3. Demonstrate methods and prototype-based behavior.

## Conclusion
This assignment introduces object creation, reusable constructors, and prototype-based inheritance in JavaScript.
