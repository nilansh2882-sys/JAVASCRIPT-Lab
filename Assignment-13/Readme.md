# Assignment 13: Functional Array Methods

## Aim
To learn how `reduce()`, `some()`, `every()`, and `map()` process array data.

## Theory

### 1. reduce()
The `reduce()` method processes array elements and combines them into a single accumulated result, such as a sum or total.

### 2. some()
The `some()` method returns `true` if at least one array element satisfies the supplied condition. Otherwise, it returns `false`.

### 3. every()
The `every()` method returns `true` only if all array elements satisfy the supplied condition. For an empty array, it returns `true`.

### 4. map()
The `map()` method calls a callback for each array element and creates a new array from the returned values.

### 5. Benefits
These methods support expressive data processing and often avoid the need to write explicit loops for common operations.

## Tasks
1. Calculate a total using `reduce()`.
2. Test conditions using `some()` and `every()`.
3. Transform marks using `map()`.

## Conclusion
This assignment demonstrates common functional programming techniques for processing JavaScript arrays.
