# Assignment 12: Function Methods and Callbacks

## Aim
To understand function reuse, callbacks, and common JavaScript function techniques.

## Theory

### 1. Callbacks
A callback is a function passed to another function as an argument. The receiving function can invoke it to perform a particular action.

### 2. Function Reuse
Functions can accept other functions as parameters, allowing the same logic to work with different operations.

### 3. Applying a Function Repeatedly
A function can receive a value, transform it, and return a result. Calling a transformation multiple times allows repeated processing.

### 4. Formatting Data
Functions can format values such as marks or messages into readable output. Separating formatting logic from other code improves maintainability.

## Tasks
1. Apply a function twice to a value.
2. Format marks using a function.
3. Repeat an action using a callback or function reference.

## Conclusion
This assignment demonstrates reusable function logic, callbacks, and techniques for processing values.
